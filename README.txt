TradeTrack PWA package

This is an installable Progressive Web App package, not a compiled APK.
To install on Android:
1. Host the contents of this folder on an HTTPS website (GitHub Pages, Netlify, or your own hosting).
2. Open that HTTPS address in Chrome on Android.
3. Tap Chrome menu (⋮) > Install app / Add to Home screen.

Features:
- Multiple independently tracked accounts
- Account-specific balance, profit goal, drawdown and daily loss settings
- Daily checklist and custom goals
- Trade journal that updates the selected account's equity and daily P&L
- JSON export/import backups
- Best-effort browser notification reminder
- Offline cache after first successful visit

Important:
- No live Alpha Capital integration; enter/update account figures yourself.
- This app is a personal tracker, not financial advice or a prop-firm rule validator.
- Browser notifications are best effort. Reliable scheduled background notifications generally need a native Android app or a push-notification server.
- Data is stored in browser local storage. Export backups regularly.
